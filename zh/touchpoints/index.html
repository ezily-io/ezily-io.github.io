Checkout 團購管理介面

讓顧客的選擇，
帶他去下一步

問答、掃碼和購買紀錄，幫你決定推薦什麼。

  1. 了解喜好

    顧客回答幾個問題，或掃包裝上的 QR code 集點。

  2. 推薦商品

    依照他選過的商品，邀請他看相關商品或活動。

  3. 完成購買

    商品和活動資訊放在一起，選好就能下單。

  4. 再次聯繫

    記下他買了什麼，下次有合適的商品再通知他。
